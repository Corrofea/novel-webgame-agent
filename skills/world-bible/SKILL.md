# 世界观构建：分层摘要 + 主旨/基调提炼

## 输入
- `runtime/<书>/chunks.json`（或长篇的分卷摘要文件）
- 可选：`runtime/<书>/characters.json`（人物摘要，与人物卡技能互相引用）

## 输出
- `runtime/<书>/bible/world.md` —— 世界观圣经（Markdown）：
  1. **主旨**：一句话主题 + 深层命题（"作者想表达什么"）
  2. **世界观**：时代背景、核心设定、力量体系/社会结构、规则与限制
  3. **情感基调**：整体氛围词（如"苍凉"、"温暖治愈"）+ 每卷情绪曲线
  4. **时间线**：重要事件年表（章节 → 事件 → 影响）
  5. **地点清单**：每个地点的作用与氛围
  6. **势力/阵营**：若存在，列出与关系
  7. **风格定调**：UI 风格建议（指向 templates/themes/ 的主题 id 与理由）

## 流程（分层压缩）
1. **单块摘要**（上下文 = 块文本 + 已有人物卡）：每块产出 150~300 字摘要，标注：新出现人物/地点/势力、关键事件、伏笔、情绪变化
2. **分卷合并**（长篇）：卷内摘要合并为卷摘要（300~500 字）
3. **全书合成**（上下文 = 全部摘要，严禁塞入原文）：产出 world.md
4. **主旨与基调提炼**：单独一次调用，专注"这本书玩起来应该是什么感觉"，输出风格定调

## 质量要求
- 摘要必须**忠于原文**：不得编造原文不存在的情节（宁缺毋滥，标注"原文未提及"）
- 人物情感转变必须记录（好感度设计依赖此信息）
- 伏笔单独成节：伏笔 → 埋设章节 → 回收章节，供解谜模式（puzzle）使用
- 矛盾记录：发现原文矛盾时记录（QA 用），不要擅自"修正"
- 输出必须写入 bible/world.md，不得只在对话中回答

## 注意事项
- 上下文预算：摘要阶段每轮注入 ≤ 40000 字符（含摘要历史），长篇按卷分批
- world.md 是后续所有阶段的唯一事实源，质量直接决定游戏品质
- 风格定调要给出具体理由（例：'基调苍凉孤独 → scifi 或 noir 主题'）
