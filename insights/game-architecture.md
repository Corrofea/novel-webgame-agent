# 任务列表
1. 游戏模式设计：设计三种游戏模式供用户选择，形式都是以文字为主，附带少量插图。（例如，是文字交互对话模式，还是书本阅读模式，还是2D模式；RPG还是其他类别；游戏和新玩法是什么，做选择，还是闯关类。可以参考玩过的各种游戏，图寻、穿越鳌太线、炒饭小测验……）。需要完整的游戏方案模板，一定要足够详尽，足够细节。（参考图寻就可以是类似于给出书中的某些细节猜情节或者人物，总之发挥想象）
2. 文本处理skill：①根据设计的游戏模式，编写对应的文本处理skill。一本小说，在这样一个游戏模式下，应该怎么掰开揉碎，要按照章节板块切分，还是提取出某些内容，还是要打碎重组故事线……。②需要一个skill来制作人物信息卡片。整理小说中的人物各种方面的信息，还有名称（一个人物可能有很多不同的称呼，要用于实体消歧）
3. 美工音乐：①需要先找几种画风图片模板作为输入，以便统一一次生成的游戏中所有图片的画风（找那种比较好模仿的AI易理解的）②需要一个skill根据场景描述能够生成对应图片③需要一个skill根据人物卡片以及相关情节能够绘制人物立绘④需要整理一个bgm音频库（纯音乐，便于循环），至少20首歌，打上情绪标签，用于游戏内播放
4. agent开发

小说、故事、剧本（强叙事性，单主角）
（叙事冒险）：判断环境是否对于人物决策影响巨大？他人对于人物决策是否影响巨大？

最终整体效果：类似于爽文中的男女主系统，玩家通过选项（例如，在遇见某个人时，可以选择踹他一脚或者打招呼或者直接无视三个选项）来影响AI的下一步决策判断以及故事背景的改变。

举例：在晚自习的时候，我们玩过一个穿越小游戏，当时的穿越主角被命名成了何承阳。然后最终通过选择成为了太后。我的想法是做一个类似于那样风格的游戏。

说明：“环境对人物影响巨大”指的是人物（主角）所作出的抉择影响了环境，最终这种环境的变化会影响人物的决策可能（比如主角面临处置某一重要人物生死的抉择，原著选了生，玩家选了死，整个世界线就变了。）；“他人对于人物决策”影响巨大指的是主角和某几个人物的关系贯穿了大部分文本，如果变动很多文本逻辑将不成立。

历史文献、编年史（强信息量）、散文、诗歌（强意境/开放性）、哲学著作、思辨文本（强观点）

最终整体效果：类似于猫国建设者（成东广狂喜）一样的策略面板

侦探小说、推理文本（强逻辑）
（解谜类）：判断环境主导或人物主导，随后决定调用S1/S2。主体为S3的调用

说明：一般来说，侦探小说不会对大的环境有什么巨大的影响，所以只是需要一个判定。如果真有其实和G1也没什么区别。S3的调用指的是由于侦探推理可能就发生在几个人之间，所以每个人身边的微环境必然会收到主角决策的影响（可以设置多种主角的体验），所以需要不断模拟每一个人的视角，从而让S1去生成新的人物行为，以符合逻辑

最终效果设想：玩家通过和人物对话推进进度，界面可以设计得像微型galgame？

史诗、多体裁名著（强综合性）
（混合/实验类）

说明：想了一下，其实还是类似于小说和剧本，不过需要多设几条线。即多安排几个主角（都是玩家可以体验的那种，不是主要任务），主角和主角之间可以平行，也可以相连（即，一个人死了可以转生成另一个人，为的是防止百年孤独那样的问题出现）。然后引入S4觉得是需要尊重一下名著，通过对比玩家和原文的不同选择来深化认识

最终效果设想：类似于郭景添和万欣琪的那种游戏界面（参考与当前novel-webgame-agent并列的仓库“ClickMacondo“）一个旁批之类的东西，阐释原文这样写的深意，可以联系时代背景，相关历史等等。
