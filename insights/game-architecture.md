# 任务列表
1. 游戏模式设计：设计三种游戏模式供用户选择，形式都是以文字为主，附带少量插图。（例如，是文字交互对话模式，还是书本阅读模式，还是2D模式；RPG还是其他类别；游戏和新玩法是什么，做选择，还是闯关类。可以参考玩过的各种游戏，图寻、穿越鳌太线、炒饭小测验……）。需要完整的游戏方案模板，一定要足够详尽，足够细节。（参考图寻就可以是类似于给出书中的某些细节猜情节或者人物，总之发挥想象）
2. 文本处理skill：①根据设计的游戏模式，编写对应的文本处理skill。一本小说，在这样一个游戏模式下，应该怎么掰开揉碎，要按照章节板块切分，还是提取出某些内容，还是要打碎重组故事线……。②需要一个skill来制作人物信息卡片。整理小说中的人物各种方面的信息，还有名称（一个人物可能有很多不同的称呼，要用于实体消歧）
3. 美工音乐：①需要先找几种画风图片模板作为输入，以便统一一次生成的游戏中所有图片的画风（找那种比较好模仿的AI易理解的）②需要一个skill根据场景描述能够生成对应图片③需要一个skill根据人物卡片以及相关情节能够绘制人物立绘④需要整理一个bgm音频库（纯音乐，便于循环），至少20首歌，打上情绪标签，用于游戏内播放
4. agent开发
