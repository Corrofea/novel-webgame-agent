# Skill 2：叙事解构师（Narrative Deconstructor, S2）

## 功能描述
针对非线性、多视角、意识流或时间线交错的小说，自动将全书内容整理并生成为一个结构化的 **JSON 文件**。该 JSON 文件严格包含三大板块：① 原书阅读顺序的内容分块概括；② 客观绝对时间顺序的内容分块概括；③ 主要人物视角下的独立内容概括（不同人物分开）。此 Skill 旨在为 AI 分析、数据可视化或深度研究提供机器可读的叙事结构数据。

---

## 输入格式
用户需要提供以下信息：
- `novel_title`：小说名称（用于 JSON 根键）。
- `main_characters`（可选）：主要人物名单。若不提供，AI 将根据出场频率和叙事权重自动识别（建议 3~5 人）。
- `raw_text`：小说的完整文本（或分段粘贴，或上传文件）。

---

## 输出格式
**输出应为一份合法的 JSON 文件**，其顶级结构如下：

```json
{
  "novel_title": "string",
  "generated_date": "ISO 8601 date string",
  "sections": {
    "original_order": [ ... ],
    "chronological_order": [ ... ],
    "character_perspectives": { ... }
  }
}

# 板块一：
original_order（原书顺序内容分块概括）
类型：Array

每个元素为一个 object，描述原书一个连续片段（通常按章或自然分隔）。

字段说明：

segment_id：唯一标识符，如 "S01"。

chapter_ref：该片段对应的原书章节或页码范围（如 "第三章"）。

summary：该片段的概括性文字（保留闪回、插叙、心理独白，但注明类型）。

contains_flashback：布尔值，是否包含明显的时间倒错。

contains_stream_of_consciousness：布尔值，是否有大段内心独白。

associated_characters：此片段中出现的人物列表（数组）。

# 板块二：chronological_order（严格时间顺序内容分块概括）
类型：Array

每个元素为一个 object，描述故事世界中一个不可再分的核心事件。

字段说明：

event_id：唯一标识符，如 "E001"。

time_label：该事件对应的客观时间描述（如 "1910年6月2日清晨"）。

time_rank：数字，表示整条时间轴上的排序（从 1 开始递增）。

summary：该事件的客观叙述（剥离主观情绪，只保留动作、对话、环境变化）。

participants：参与该事件的人物列表。

uncertainty（可选）：若时间无法精确定位，此处注明推测依据（如 "推测在 1898 年夏"）。

# 板块三：character_perspectives（主要人物视角内容概括）
类型：Object

键为人物名称（字符串），值为该人物的视角条目数组。

每个条目为一个 object，字段包括：

subjective_time：该人物心理时间轴上的定位（例如 "木月死后两个月"）。

event_summary：从该人物视角所见、所想的内容（允许主观色彩和记忆偏差）。

objective_event_ref（可选）：若该内容可对应到 chronological_order 中的某事件，填写其 event_id。

核心逻辑与执行步骤
预处理与分段：将输入文本按章节或自然分隔符切割为若干逻辑单元（Segments），并编号（S1, S2, ...）。

第一轮扫描（原书顺序摘要）：直接对每个 Segment 进行压缩概括，生成 original_order 数组。标记出其中的闪回、插叙、预测等非当下线索。

第二轮扫描（时间锚定与排序）：

提取所有 Segment 中的时间提示词。

建立绝对时间坐标轴，并将每个 Segment 中描述的“当下事件”挂载到时间轴对应的点上。

按时间轴顺序写出 chronological_order 数组。

第三轮扫描（视角归属）：

根据对话和叙述视角，将每个 Segment 中的内容分配给对应的人物。

以人物为单位，提取出属于该人物的所有内容，按该人物的心理时间流组织成 character_perspectives 对象。

质量控制：确保三大板块之间的内在一致性（例如，时间点应能交叉引用）。

注意事项
允许不确定性：若事件绝对时间无法确定，在 chronological_order 中标注 uncertainty 字段，不要硬编。

保持中立与客观：摘要内容应尽可能使用中性语言，避免添加文学评论。

灵活处理极端意识流：对于纯情绪描写（无任何时空线索），可在 chronological_order 中略去，但 original_order 和 character_perspectives 中必须保留。
